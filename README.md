# QR Studio

QR Studio is a simple and fast QR code generator available for **Android** and **Web**.  
It allows users to create QR codes instantly for text, links, and more.

---

## 📱 Platforms

- ✅ Android
- 🌐 Web

---

## ✨ Features

- Generate QR codes instantly
- Clean and easy-to-use interface
- Works offline (Android)
- Lightweight and fast
- Free to use

---

## 📥 Download

You can download the latest version from the **Releases** page:

👉 https://github.com/sibintb/qr-studio/releases

### Android
- Download the `.apk` file
- Enable **“Install from unknown sources”** if prompted
- Install and open the app

### Web
- Download the Web build or open the hosted version (if available)
- Open `index.html` in your browser
